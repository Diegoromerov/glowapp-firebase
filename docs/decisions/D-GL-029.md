# D-GL-029: Multi-carrier unificado con Envíame

**Fecha:** 2026-11-15
**Estado:** APROBADA
**Autoridad:** Director

## Decisión
Usar **Envíame** como plataforma multi-carrier unificada para la logística de reparto de GlowApp.

## Justificación
- Time-to-market: una sola integración vs 4+ APIs directas
- 20+ transportadoras colombianas disponibles (Inter Rapidísimo, Coordinadora, Servientrega, TCC, Envía, 4-72, etc.)
- Validación nativa de direcciones colombianas con códigos DANE
- API unificada: rates, labels, tracking, pickup, address validation
- Marketplace-ready: soporta multi-seller (proveedores/salones despachando desde ubicaciones distintas)
- Webhooks estandarizados para tracking en tiempo real

## Alcance
- Fase 1: Estructuras BD + cliente Envíame (mock/placeholder)
- Fase 2+: Integración real cuando estén listas las cuentas carrier y credenciales

## Exclusiones
- No se integran APIs directas de carriers (Inter, Coordinadora, etc.) salvo fallback extremo
- Las credenciales `ENVIAME_API_KEY` y `ENVIAME_WEBHOOK_SECRET` se configurarán en Railway cuando el Director las provea

## Referencias
- Investigado: Envíame es la mayor multicourier de Colombia (fuentes: enviame.io, tiendanube.com, marketing4ecommerce.co)
- Ranking 2025: Inter Rapidísimo ($1.2B), Coordinadora ($893M), Servientrega ($727M) — todas en Envíame
