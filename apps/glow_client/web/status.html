Cómo se vigila el servicio

El servicio expone /api/health, que devuelve el estado de la API y de la base de datos sin exigir autenticación. Un monitor externo puede consultarlo cada minuto; esta página usa ese mismo endpoint, así que lo que ves aquí es la misma señal que recibiría el monitor.

Si la API aparece en rojo pero la app sigue funcionando, es probable que tu red esté bloqueando la consulta: esta comprobación se hace desde tu navegador, no desde nuestros servidores.
